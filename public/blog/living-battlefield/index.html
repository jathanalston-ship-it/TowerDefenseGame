The Living Battlefield: making the ground remember your run

By late game the arena should no longer resemble the map you started on. Here is how the terrain now evolves with your build — veins, frontiers, flora and eyes — without costing a frame.

ASSIMILATE has always been about growth, but until recently the ground you fought on stayed politely inert. That changed with the Living Battlefield: a terrain layer that assimilates alongside your run.

One hidden number

Everything you build feeds a hidden assimilation state — tower count and depth (strains, branches, stars, mastery, grafted organisms), heroes and their equipment, kills, bosses, wave depth, your Power Score, even the biome. That state drives an evolution stage from 0 (pristine terrain) to 5 (an unmistakably alive biomechanical ecosystem), shared with the music and HUD so the whole presentation deepens together.

Mutation spreads from the build

The membrane doesn't tint uniformly — it radiates outward from every tower and pools up from the hive, merging as the run deepens. A vein network grows through your actual layout (each tower joins its nearest connected neighbor, so the network branches organically), nutrient beads pulse along it in time with a shared heartbeat, and parasites crawl the channels. At the deepest stages the terrain opens eyes that track the nearest enemy.

The performance trick

All of the stable terrain is baked into two cached canvases — a base layer that breathes and a glow layer whose alpha rides the heartbeat — rebuilt only when the run actually changes and crossfaded so the arena grows instead of popping. A steady frame costs two draw calls. The whole system is render-only: the deterministic simulation never reads it, so replays and leaderboards are untouched.

A screenshot of a deep run now tells you how deep it is, what the player built, and how thoroughly the environment has been consumed — which was the point all along.
